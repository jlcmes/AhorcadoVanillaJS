# Juego del Ahorcado realizado en JS sin frameworks

Este es un ejemplo de un juego de ahorcado básico para los alumnos de DAM y SMR.
Parte del código fue generado por IA (ChatGPT) pero se ha reestructurado por completo para
facilitar la lectura y seguimiento del código JS y CSS (verión de IA original en el primer commit)
y se ha comentado en español.

# Características

No se utilizan frameworks JS.
No se utilizan funciones con operador flecha => de Javascript pero sí funciones Lambda.
Se utilizan todo tipo de selectores y clases en CSS.
No se incluyeron gráficos ni se pinta el muñeco del ahorcado para facilitar el código.
Gran parte de la interfaz se genera de manera dinámica por JS.
